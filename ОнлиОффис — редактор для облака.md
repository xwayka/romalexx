# OnlyOffice — редактор для облачного хранилища

[[ROMALEX]] | [[ROMALEX/Облачное хранилище ROMALEX — концепт]] | [[ROMALEX/Ребилд архитектуры БД]]

## Что это

Бесплатная замена Microsoft Office. Открывает и сохраняет `.docx`, `.xlsx`, `.pptx` с максимальной совместимостью — работники не заметят разницы с Excel и Word.

Две версии:
- **OnlyOffice Desktop** — локальная программа, бесплатно без ограничений
- **OnlyOffice Document Server** — редактор прямо в браузере, как Google Docs, но на своём сервере

## Почему OnlyOffice, а не Collabora

Collabora — это LibreOffice в браузере. Форматирование `.xlsx` иногда съезжает. OnlyOffice написан с нуля под совместимость с форматами Microsoft — для нас это важнее, потому что все работают в Excel.

## Community Edition — ограничения

Бесплатная версия (Community Edition) ограничена **20 одновременными подключениями**. Для ROMALEX этого хватит с запасом — вряд ли 20 человек одновременно редактируют один файл.

Платная версия нужна только при 20+ одновременных пользователях.

## Как поднять

Поднимается в Docker одной командой. Интегрируется в облачное хранилище как отдельный сервис.

```
Docker: onlyoffice/documentserver
Порт: 80 / 443
RAM: ~2-4 GB
```

## Статус

Выбран как редактор для таблицы учёта в облаке. Поднимаем вместе с основным хранилищем на Minisforum UM790 Pro.
