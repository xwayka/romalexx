# Ребилд архитектуры БД — таблица учёта ROMALEX

[[ROMALEX]] | [[ROMALEX/Облачное хранилище ROMALEX — концепт]]

## Решение

Таблица учёта материалов переезжает в облачное хранилище ROMALEX как `.xlsx` файл.

**Логика:** Все работники уже пользуются таблицей в формате Excel. Поддерживать отдельную SQLite БД с FastAPI — это дублирование одних и тех же данных в двух местах. Оптимизация: один файл на облаке, один источник правды, доступ через браузер по правам.

Создавать отдельную БД под каждую таблицу — не нужно. Облако решает задачу хранения и доступа, Excel решает задачу редактирования.

## Что происходит

- Облачное хранилище поднимается на **Minisforum UM790 Pro** (приедет начало июля)
- Таблица учёта хранится как `.xlsx` в разделе Документов
- Доступ: Admin (Арсений) обновляет файл, работники — чтение по разрешению
- FastAPI+SQLite (текущая система) — использовалась для первоначального занесения данных, после переезда не нужна
