**Основа:** тёмно-серый / чёрный + оттенки серого. Белый и светло-серый для текста.

**Акцентные цвета по разделам** (у каждого раздела свой цвет):

| Раздел | Акцентный цвет |
|---|---|
| Дашборд | синий |
| Документы | жёлтый (как папки в проводнике Windows) |
| Граф | фиолетовый (как в Obsidian) |
| Личное | зелёный |
| Заметки | (уточнить) |
| Проекты | (уточнить) |

**Стиль блоков:** glassmorphism («жидкое стекло») — каждый блок/карточка имеет `backdrop-filter: blur()` + полупрозрачный фон.

---

### Навигация — pill-стиль

- Убрать прямоугольные блоки-иконки (квадратики/боксы)
- Пункты навигации → pill-форма (скруглённые таблетки)
- Активный пункт получает акцентный цвет своего раздела + glow (`box-shadow`)

**Убрать из сайдбара:**
- Раздел «Теги» — удалить полностью
- «Учёт проектов» — убрать выпадающий список и стрелку, сделать просто пунктом

**Структура групп:** ГЛАВНОЕ / ЛИЧНОЕ / ПРОЧЕЕ — сворачиваются по клику

---

### Маршрутизация разделов (фикс)

Каждый раздел открывает свой экран, никаких перебросов:
- Недавние → свой экран (не Дашборд)
- Заметки → свой экран (не Личное)
- Проекты → свой экран (не Документы)

### Что было реализовано по итогу сессии

- Сайдбар: `background: rgba(12,12,14,0.35)` + `backdrop-filter: blur(80px) saturate(180%)`
- `body::before` — белые radial-gradient блобы (opacity 0.12–0.18) как фоновый слой для блюра
- `.sb-pill` — полноширинные pill-блоки с `border: 1px solid rgba(255,255,255,0.09)` пассивно, акцентный цвет + glow активно
- Иконки без квадратного блока (`border: none; background: none`)
- Акцентные цвета: Дашборд=blue, Документы=amber, Граф=purple, Учёт проектов=orange, Личное=green, Заметки=pink, Избранное=lime, Недавние=cyan, Корзина=red
- «Теги» удалён из nav и dashboard
- «Учёт проектов» — убрана выпадашка и стрелка
- Группы ГЛАВНОЕ / ЛИЧНОЕ / ПРОЧЕЕ — сворачиваются
