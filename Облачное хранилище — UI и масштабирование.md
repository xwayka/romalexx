## Запуск бэкенда

Создана полная структура проекта `D:\vibecoding projects\romalex - облачное хранилище\`:

```
backend/
  main.py         ← FastAPI, 15+ эндпоинтов
  database.py     ← 6 таблиц SQLite + seed admin
  auth.py         ← JWT + bcrypt
  requirements.txt
  .env            ← PORT=8001, SECRET_KEY, UPLOAD_DIR
  start.bat       ← запуск через venv
  venv/           ← Python 3.12, все пакеты

frontend/
  index.html
  style.css
  app.js
```

**Два бага при первом запуске — оба исправлены:**

1. **bcrypt 5.x несовместим с passlib 1.7.4** — ошибка `module 'bcrypt' has no attribute '__about__'`. Решение: добавить `bcrypt<4.0.0` в requirements.txt → установился bcrypt 3.2.2.

2. **Deprecated `@app.on_event("startup")`** — предупреждение FastAPI. Решение: заменить на `@asynccontextmanager lifespan(app)` (современный паттерн).

Сервер работает на порту **8001**. Логин `admin` / `admin123` протестирован — JWT токен возвращается корректно.

## Масштабирование UI

Исходные шрифты в CSS были 9–14px — слишком мелко для рабочего интерфейса. Прошли два итерации:

**Итерация 1:** +2px к каждому размеру шрифта. Пользователь сказал мало — "надо на 10 пкс".

**Итерация 2:** +10px к каждому размеру шрифта. Шрифты стали 19–32px — читаемо, но блоки остались старого размера → не пропорционально.

**Итерация 3 (финальная):** Пропорциональное масштабирование всего UI (~1.5x от оригинала):
- Sidebar: `220px` → `320px` в grid-template-columns
- Explorer tree panel: `248px` → `360px`
- Graph panel: `268px` → `380px`
- Document panels: `196px/208px` → `280px/300px`
- Padding везде: примерно ×1.5 (напр. `padding: 14px 16px` → `20px 24px`)
- Иконки fl-ico: `30×30px` → `46×46px`
- Кнопки bar-btn: `30×30px` → `44×44px`
- Border-radius: `10-12px` → `14-18px`
- Tile grid: minmax `130px` → `180px`
- Topbar table: высота `48px` → `70px`
