# Telegram-бот — ROMALEX

[[ROMALEX]]

---

## Назначение

Бот для приёма заявок от потенциальных клиентов компании Ромалекс. Пользователь проходит через FSM-воронку, заполняя контактные данные и описание задачи. По завершении — алерт в группу менеджеров.

---

## Технический стек

- **Python 3.10+**
- **aiogram 3.x** — асинхронный Telegram Bot API
- **SQLite** — хранение заявок
- **FSM (Finite State Machine)** — пошаговая воронка сбора данных

---

## FSM-воронка (шаги)

1. **ФИО + компания** — как обращаться, название организации
2. **Телефон** — для обратной связи
3. **Email** — для документации
4. **Тип объекта** — промышленный / коммерческий / жилой / другой
5. **Описание задачи** — свободный текст, что нужно сделать
6. **Подтверждение** — показывает сводку, кнопки «Отправить» / «Изменить»

---

## Уведомления

При каждой заявке в `ADMIN_GROUP_ID` отправляется алерт с:
- Порядковым Request ID
- Всеми данными заявки
- Временем отправки

---

## Переменные окружения (.env)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | Токен Telegram-бота |
| `ADMIN_GROUP_ID` | ID группы менеджеров для алертов |
| `MANAGER_PHONE` | Телефон менеджера (показывается пользователю) |
| `MANAGER_EMAIL` | Email менеджера |
| `MANAGER_TG` | @тег менеджера в Telegram |
| `PROXY_URL` | Прокси для обхода блокировок (опционально) |

## Статус

Бот реализован в рамках первого клиентского проекта ROMALEX. Является частью общего пакета услуг (лендинг + бот). Деплой — отдельно от таблицы учёта, требует собственного сервера или хостинга ботов.

Текущий статус деплоя: **не задеплоен** (лежит локально, ждёт решения по хостингу).
