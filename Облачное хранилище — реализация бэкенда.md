## Что произошло

Создан полноценный FastAPI-бэкенд и разделённый фронтенд для внутреннего облачного хранилища ROMALEX. Проект поднят в новой папке `D:\vibecoding projects\romalex - облачное хранилище\`, зависимости установлены, сервер запущен и авторизация проверена — логин `admin/admin123` работает, JWT токен возвращается корректно.

Архитектура такая же, как в таблице учёта (`romalex - таблица учета`): FastAPI + aiosqlite + JWT через python-jose + bcrypt. Порт 8001 — чтобы не конфликтовать с таблицей учёта (порт 8000).

## API эндпоинты

| Метод | Путь | Роль |
|---|---|---|
| POST | `/api/login` | публичный |
| GET | `/api/me` | auth |
| GET/POST/DELETE | `/api/users` | admin |
| GET/POST/DELETE | `/api/folders` | auth / admin |
| GET | `/api/files` | auth |
| POST | `/api/files/upload` | auth |
| GET | `/api/files/{id}/download` | auth |
| DELETE | `/api/files/{id}` | admin |
| GET | `/api/activity` | auth |
| GET/POST | `/api/tags` | auth / admin |
| GET | `/api/stats` | auth |

## SQLite схема (6 таблиц)

- `users` — id, username, name, password (bcrypt), role (admin/employee), created_at
- `folders` — id, name, parent_id, owner_id, created_at
- `files` — id, name, path, size, mime_type, folder_id, owner_id, is_public, created_at
- `tags` — id, name, color
- `file_tags` — file_id + tag_id (many-to-many)
- `activity` — id, user_id, file_id, action (upload/view/delete), detail, created_at

Seed: `admin` / `admin123` создаётся автоматически при первом запуске.

## Технические решения и фиксы

**bcrypt несовместимость:** `passlib 1.7.4` не работает с `bcrypt 5.x` — ошибка `module 'bcrypt' has no attribute '__about__'`. Решение: принудительно `bcrypt<4.0.0` в requirements.txt → установился bcrypt 3.2.2.

**Deprecated `@app.on_event("startup")`:** Заменено на `@asynccontextmanager lifespan(app)` — современный способ в FastAPI.

**StaticFiles:** `app.mount("/", StaticFiles(directory=FRONTEND_DIR, html=True))` — сервер отдаёт фронтенд по `/`, API доступно по `/api/*`. Порядок важен: сначала все API-роуты, потом `mount`.

**Auth flow на фронтенде:** Login overlay (`#loginOverlay`) скрыт по умолчанию. При загрузке — `checkAuth()` → `/api/me`. Если 401 → `showLogin()`. После успешного логина — `hideLogin()` + `initApp()`. Токен хранится в `localStorage` как `cloud_token`.
