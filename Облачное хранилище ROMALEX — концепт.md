## Ключевые решения

- Хранилище на своём железе (Minisforum UM890 Pro, приедет начало июля)
- Стек: **Nextcloud + OnlyOffice CE + Docker + FastAPI**
- Разграничение: общий диск ~1TB + личное хранилище 10GB на сотрудника
- Роли: Арсений (admin) / Директора / Сотрудники
- Доступ только через Tailscale / NetBird (не публичный интернет)
- Таблица учёта переезжает как .xlsx в Nextcloud, редактирование через OnlyOffice
- Граф связей как в Obsidian — для всех файлов системы
- AI-ассистент (Gemma 4 26B A4B MoE, llama.cpp + Vulkan) встроен в сайдбар
