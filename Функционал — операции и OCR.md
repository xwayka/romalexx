## Добавление операций

### Для кого

Добавлять операции может только авторизованный пользователь (кнопка «Войти» в шапке). Просматривать таблицу — все, без входа.

### Как добавить приход или расход

1. В таблице навести мышью на строку с нужной позицией
2. Появляется кнопка `+` (admin-only) справа от названия
3. Нажать — открывается модальное окно
4. Заполнить поля:
   - **Склад** — Киржач / ГСК 2 / ГСК 3
   - **Тип** — Приход / Расход
   - **Количество** — число
   - **Дата** — datepicker
   - **Поставщик / Подрядчик** — текст (для прихода — поставщик, для расхода — ФИО монтажника)
   - **Номер накладной** — текст
5. Нажать «Сохранить» → POST `/api/operations` → таблица обновляется

### Что происходит в базе

Каждая операция сохраняется отдельной записью в таблице `operations`. Это полная история движений материала. Никаких суммарных значений — всё хранится в сырых операциях, агрегация происходит при запросе (SUM GROUP BY).

## История операций (панель-слайдер)

### Как открыть

Кликнуть на ячейку **Приход** или **Расход** в таблице. Справа выезжает панель.

### Режимы

**Режим 1 — по ячейке:** кликнул на «Киржач — Приход» в строке «Труба 12.7×0.81» → показывает только приходы на Киржач по этой позиции. Колонки Склад и Тип в таблице скрыты (они известны из заголовка панели).

**Режим 2 — по позиции:** кликнул на название материала → показывает ВСЕ операции по этой позиции: все склады, все типы. Полная история.

### Удаление операции

В режиме admin — каждая строка панели истории имеет кнопку `✕`. Клик → DELETE `/api/operations/{id}` → панель обновляется.

## OCR накладных через Claude Haiku

### Зачем

Монтажник привозит материал с накладной на листе бумаги. Без OCR нужно вручную открыть сайт, найти каждую позицию, ввести количество. Это 5–10 минут на накладную при 20+ позициях. С OCR — сфотографировал, проверил матчинг, нажал «сохранить всё».

### Как работает (шаги пользователя)

1. Нажать кнопку «Загрузить фото» в project-bar (admin-only)
2. Открывается модальное окно с зоной drag-and-drop
3. Загрузить фото накладной (JPEG/PNG/HEIC с телефона)
4. Нажать «Распознать» → появляется спиннер
5. Фото летит на сервер → Claude Haiku анализирует изображение
6. Возвращается список позиций: название, количество, единица
7. В интерфейсе каждая позиция из OCR показывается с выпадающим списком: выбрать соответствующую позицию из нашей базы (или «пропустить»)
8. Нажать «Сохранить все» → все выбранные позиции записываются операциями прихода

### Как работает (технически)

```
Фото (base64) → POST /api/upload-photo →
FastAPI → httpx → misaku.net (прокси) →
Claude Haiku (vision) → JSON {warehouse, items} →
Фронтенд матчинг → POST /api/operations (×N)
```

Промпт для Claude Haiku:
```
Ты помощник для распознавания накладных на строительные материалы.
Из фото накладной извлеки:
- склад назначения (если указан)
- список позиций: название, количество, единица измерения
Ответь ТОЛЬКО JSON без пояснений:
{"warehouse": "...", "items": [{"name": "...", "qty": N, "unit": "..."}]}
```

### SSL и retry

VPN перехватывает HTTPS-трафик → SSL-верификация отключена (`verify=False`). Прокси иногда возвращает 503 → retry 3 попытки × 3 сек пауза.

## Экспорт Excel

### Как работает

Кнопка «Экспорт Excel» → SheetJS в браузере последовательно запрашивает `GET /api/items/{tab}` для каждой из 8 вкладок → собирает `.xlsx` целиком на клиенте → скачивается файл. Отдельного API-эндпоинта для экспорта нет.

### Структура файла

Один `.xlsx` с 8 листами (по одному на каждую вкладку: Труба, Изоляция, Автоматика, Электрика, Проходки, Дренаж, Расходник, СИЗ). Каждый лист — полная таблица со всеми колонками.

### Имя файла

```
Ромалекс_таблица учета_ЖК Рязанский пр вл.26-1 ГСК 2-3_актуально на_DD.MM.YYYY.xlsx
```

Дата — это `MAX(date)` из таблицы `operations` (дата последней записанной операции, не время скачивания). Запрашивается через `GET /api/last-update` перед сборкой файла.

### Модалка после скачивания

После скачивания появляется уведомление «Файл загружен». Кнопка закрытия имеет обратный отсчёт 2 секунды (2→1→×). Пока таймер — кнопка выглядит как белая пилюля с числом, не как ×. Клик мимо модалки заблокирован пока таймер не истёк. Это даёт пользователю время прочитать сообщение и подтвердить что файл действительно скачался.
