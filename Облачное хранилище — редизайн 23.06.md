## Решение по дизайну

Полный редизайн UI облачного хранилища. Цветовая концепция утверждена голосом.

### Цветовая схема

- **База:** чёрный + тёмно-серый + серый оттенки (тёмная тема)
- **Акцентные цвета по разделам:**
  - Dashboard → синий
  - Документы → жёлтый (как папки в проводнике)
  - Граф → фиолетовый (как Obsidian)
  - Личное → зелёный
  - Заметки, Проекты — цвет не определён, решим по ходу

### Стиль блоков

Glassmorphism (жидкое стекло) на каждом блоке — `backdrop-filter: blur`, полупрозрачные фоны, тонкие бордеры.
