# Облачное хранилище — UI доработки

[[Облачное хранилище — редизайн 23.06]] | [[Облачное хранилище — UI и масштабирование]]

## Что сделано

Большая сессия по доводке frontend интерфейса облачного хранилища. Основная боль — SVG иконки папок (много итераций). Также доработали dropdown меню, акцентные цвета сайдбара и таблицу файлов.

## Акцент-цвета сайдбара

- **Дашборд** переключён с синего на белый — `data-accent="white"`, новые CSS правила `.sb-item.on[data-accent="white"] .sb-pill`
- **Заметки** переключены с розового на синий — `data-accent="blue"`

## SVG иконки папок

Использована техника 3-слойного SVG:
1. Размытые листы за стеклянной панелью — `filter="url(#pblur)"`, `feGaussianBlur stdDeviation="1.8"`
2. Тёмная полупрозрачная стеклянная панель — `rgba(28,28,28,0.78)`
3. Чёткие листы поверх через `clip-path="url(#af)"` с dog-ear уголком

**Проблема со свечением:** blur с большим stdDeviation вылазил за края SVG, создавая белое свечение. Решение — `overflow: hidden` на `.fcrd-svg` в CSS.

**Dog-ear уголок (3 слоя на каждом листе):**
- Тело листа: `path M28,4 L52,4 L66,21 ...`
- Тёмный треугольник загиба: `M52,4 L66,21 L52,21Z`
- Световой highlight: `rgba(255,255,255,0.10–0.16)`
- Тень под загибом: `M52,21 L67,22 L52,22Z fill rgba(0,0,0,0.55)`

**Итоговые цвета листов:**
- rotate(14): `rgba(90,90,90,0.65)` — задний
- rotate(6): `rgba(115,115,115,0.70)` — средний
- rotate(-4): `rgba(140,140,140,0.75)` — передний

## Dropdown меню (⋮ у файлов в таблице)

- Цвет: `rgba(17,17,17,0.82)` с `backdrop-filter: blur(40px) saturate(200%)` — вписывается в фон
- Позиция: слева от кнопки — `right: calc(100% + 8px); top: 50%; transform: translateY(-50%)`
- Размер +15%: `padding: 11px 17px`, `font-size: 16px`
- Исправлена проблема: `overflow: hidden` на `.docs-ftable` блокировал `backdrop-filter` — убран, border-radius перенесён на `.dft-head`

## Таблица файлов

- Убрана кнопка «Все файлы →» из `.docs-blk-hdr`
- Сетка колонок: `grid-template-columns: 3fr 1fr 1fr 1fr 1.2fr 44px`
- Текст по всему экрану увеличен на +10%
